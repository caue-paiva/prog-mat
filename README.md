# Programação Matemática — contexto para o projeto

Repositório de materiais da disciplina e documentação para um agente implementar o projeto de **Bin Packing**. Ainda não há implementação nem resultados experimentais.

## Organização

- `enunciado/`: PDF oficial e requisitos em Markdown.
- `contexto/pdfs/`: slides e atividade de aula, com os nomes originais.
- `contexto/resumos/`: um resumo por PDF e uma síntese direcionada ao projeto.
- `contexto/inventario.json`: páginas e SHA-256 dos dez PDFs originais.
- `projeto/`: modelo base, orientação de implementação e roteiro de relatório.
- `AGENTS.md`: instruções e ordem de leitura para o próximo agente.

Os resumos consolidam slides repetidos e não são transcrições integrais. As páginas referenciadas são as posições no PDF, começando em 1. Fórmulas foram normalizadas e ressalvas sobre inconsistências aparecem nos resumos. Datas e recordes dos slides são contexto histórico, não informações atuais verificadas. O PDF oficial prevalece sobre os documentos auxiliares. Recomendações técnicas são identificadas como propostas, sem impor ao grupo uma aplicação ainda não escolhida.
